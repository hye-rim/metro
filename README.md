# 지하철 노선 연결 🚇

●■▲★ 역을 선으로 이어 열차를 다니게 하고, 승객이 원하는 모양의 역에 내려 주는 노선 설계 퍼즐입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 역을 꾹 누른 채 다른 역까지 끌었다 놓으면 선이 이어집니다(선의 처음·끝 역에서 늘림). 아래 1·2·3호선 버튼으로 선을 고르고, **🚆 열차 +** 로 쉬는 열차를 투입(45초마다 1대), **선 지우기** 로 고른 선 삭제. PC 는 숫자 `1 2 3` 으로 선 고르기, `M` 소리.
- 역에 승객이 8명 넘게 14초 쌓이면 끝. 점수는 내려 준 승객 수.
- `logic.js` 규칙(`LOGIC_METRO`), `game.js` 화면·입력·소리, `test/logic.test.js` (`node --test`).

## 균형 (시험용 봇, 20판)
가까운 역을 이어 선 3개를 늘리고 열차를 투입하는 단순 봇: 쉬움 평균 363초(808명), 보통 149초(256명). 아무것도 안 이으면 쉬움 48초, 보통 40초에 끝납니다. 노선을 잘 짜는 사람은 봇보다 오래 갈 수 있습니다.
